# NEPSE JSON data

Generated by `scripts/build_data.py` and refreshed by GitHub Actions.

- `manifest.json`: source, coverage, freshness and dataset counts.
- `symbols.json`: instrument master and per-symbol coverage.
- `market-summary.json`: latest session breadth, turnover, movers and sector performance.
- `index-history.json`: NEPSE headline index OHLC history.
- `stocks/{SYMBOL}.json`: per-security OHLCV history from 2026-01-01 onward.

The archive preserves source-published dates. Weekends, holidays and missing source rows are not filled. Stock prices are unadjusted; bonus/right issues, splits and other corporate actions can distort naive return calculations. This is an unofficial research dataset, not an official NEPSE feed or investment advice.
