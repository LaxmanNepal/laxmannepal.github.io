How the preview workflow works

Each prompt has a matching image filename based on its ID. For example, prompt #120 uses /image-prompt/images/120.webp. When the image exists, it appears as a 9:16 preview and can be opened full-screen. When it does not exist yet, the card shows a clean placeholder instead of a broken image.

Generate with Google Flow

Click “Generate in Flow” to copy the prompt and open Google Flow in a new tab. Paste the prompt into Flow, generate the image, download it as a 9:16 image, rename it to the prompt ID such as 120.webp, and place it in the site's image-prompt/images/ folder. Google Flow is the generation service; this site does not require a Gemini API key or API billing.

8K-quality note

“8K-quality” describes the desired detail and finish in the prompt. Actual output resolution depends on the generator and its available settings.
