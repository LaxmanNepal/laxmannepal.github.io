# Blog source

Add Markdown articles to this folder. Each article should start with YAML front matter:

```yaml
---
title: Your article title
description: A useful search description in one or two sentences.
date: 2026-09-11
updated: 2026-09-11
author: Laxman Nepal
category: AI
tags: AI, Productivity, Tools
image: /assets/images/blog/example.jpg
---
```

The GitHub Actions build automatically creates the article page, canonical URL, Open Graph metadata, Article JSON-LD, breadcrumbs, reading time, related links, sitemap entries and RSS entries.
