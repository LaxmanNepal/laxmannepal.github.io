API setup & privacy

Live channel statistics, video search, competitor lookups and keyword discovery use Google's YouTube Data API v3. Create an API key in Google Cloud Console, enable YouTube Data API v3, then add the key in Settings. The key is stored only in this browser's local storage and is sent directly from your browser to Google. Do not use a restricted/private key here. Set website and API restrictions in Google Cloud. SEO analysis and the content planner work without an API key.
