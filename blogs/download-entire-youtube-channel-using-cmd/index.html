How to Download an Entire YouTube Channel Using CMD

Learn how to use yt-dlp and FFmpeg to download accessible channel videos, resume interrupted downloads, choose quality, save thumbnails and more.

Published October 7, 2026 · By Laxman Nepal

Before you download: Only download videos when you have permission or a lawful right to do so. Do not bypass private access, DRM, paid-content restrictions, or other access controls.

Install yt-dlp and FFmpeg

Install yt-dlp and FFmpeg on Windows, then test them from Command Prompt.

yt-dlp --version
ffmpeg -version

Download an entire channel

Replace the URL with a channel you are authorized to download.

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "https://www.youtube.com/@CHANNEL_HANDLE/videos"

Resume-safe downloads

yt-dlp --download-archive downloaded.txt -f "bv*+ba/b" --merge-output-format mp4 "https://www.youtube.com/@CHANNEL_HANDLE/videos"

Subtitles, thumbnails and metadata

yt-dlp --write-thumbnail --skip-download "CHANNEL_URL/videos"

Common problems

Some videos can be private, removed, region-limited, members-only or otherwise unavailable. Do not attempt to bypass access restrictions.
