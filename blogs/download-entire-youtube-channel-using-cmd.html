How to Download an Entire YouTube Channel Using CMD

Want to save all accessible videos from a YouTube channel instead of downloading them one by one? On Windows, yt-dlp lets you automate channel downloads directly from Command Prompt (CMD).

Updated October 7, 2026 · By Laxman Nepal

Before you download: Only download videos when you have permission or a lawful right to do so. Do not use these commands to bypass private access, DRM, paid content restrictions, or other access controls. A successful download does not give you copyright or redistribution rights.

1. What you need

You only need a Windows PC, Command Prompt, yt-dlp, and FFmpeg. yt-dlp handles YouTube extraction and downloading, while FFmpeg is used for tasks such as merging separate video and audio streams and post-processing.

yt-dlp

The command-line downloader that accepts individual YouTube URLs, playlists and channel URLs.

FFmpeg

The media toolkit used by yt-dlp for merging and converting media when needed.

2. Install yt-dlp and FFmpeg

The simplest Windows setup is to place yt-dlp.exe and the FFmpeg executables in a folder that is on your PATH. You can also keep them in the same working folder and call them directly.

After installation, test yt-dlp:

yt-dlp --version

Test FFmpeg:

ffmpeg -version

For the official project pages, use yt-dlp on GitHub and FFmpeg.org.

3. Download an entire YouTube channel

First create a destination folder and switch to it:

mkdir "D:\YouTube\Channel-Backup"
cd /d "D:\YouTube\Channel-Backup"

Now paste your channel URL. Example:

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "https://www.youtube.com/@InjectionByRachel/videos"

Replace the URL with the channel you are authorized to download. The command asks yt-dlp to select the best available video/audio combination, merge it to MP4 when possible, and create readable filenames containing the upload date, title and video ID.

You can also use the channel URL without /videos:

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "https://www.youtube.com/@CHANNEL_HANDLE"

4. Make the download resume-safe

For a large channel, this is the command I recommend. The download archive prevents yt-dlp from downloading the same successfully completed video again if you restart the command later.

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 --download-archive downloaded.txt -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "https://www.youtube.com/@CHANNEL_HANDLE/videos"

Stop the command with Ctrl+C. Run the same command again later and yt-dlp will use downloaded.txt to skip videos already recorded as downloaded.

5. Choose video quality

Best available quality

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 "CHANNEL_URL"

Up to 1080p

yt-dlp -f "bv*[height<=1080]+ba/b[height<=1080]" --merge-output-format mp4 "CHANNEL_URL"

Up to 720p

yt-dlp -f "bv*[height<=720]+ba/b[height<=720]" --merge-output-format mp4 "CHANNEL_URL"

See available formats first

yt-dlp -F "VIDEO_URL"

6. Download subtitles, thumbnails and metadata

If you are archiving your own channel or content you are authorized to preserve, yt-dlp can save useful sidecar files too.

Automatic subtitles when available

yt-dlp --write-auto-subs --sub-langs "en,ne" --sub-format vtt --skip-download "CHANNEL_URL/videos"

Manual subtitles when available

yt-dlp --write-subs --sub-langs "en,ne" --sub-format vtt --skip-download "CHANNEL_URL/videos"

Thumbnails

yt-dlp --write-thumbnail --skip-download "CHANNEL_URL/videos"

Metadata and thumbnails with the video

yt-dlp -f "bv*+ba/b" --merge-output-format mp4 --write-thumbnail --embed-metadata --download-archive downloaded.txt -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "CHANNEL_URL/videos"

7. Download videos available to your account

Some videos are available only after you sign in. If you own the account or have explicit authorization to access the videos, yt-dlp can sometimes use your existing browser session. Do not share your browser cookie database or exported cookies with anyone.

Security warning: Browser cookies can act like login credentials. Use --cookies-from-browser only on your own computer for an account you are authorized to access. Never paste cookies into a public script, website, GitHub repository or chat.
yt-dlp --cookies-from-browser chrome -f "bv*+ba/b" --merge-output-format mp4 --download-archive downloaded.txt -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "CHANNEL_URL/videos"

For another supported browser, replace chrome with the appropriate browser name supported by your yt-dlp installation. This does not bypass authorization; it uses an authenticated session you already have access to.

8. Common problems

“yt-dlp is not recognized”

Windows cannot find the executable. Either add the folder containing yt-dlp to PATH or run it from the folder containing yt-dlp.exe.

Audio and video are not merged

Install FFmpeg and make sure its bin folder is available on PATH. Then retry the command.

Some videos fail

A channel can contain private, members-only, age-restricted, removed, region-limited or otherwise unavailable videos. A channel download is not a guarantee that every item can be downloaded. Do not attempt to defeat access restrictions.

Downloads are very slow

Speed can depend on your network, YouTube delivery, the selected formats and throttling. Do not assume that changing the command will always increase speed.

9. A practical all-in-one command

For a normal public channel that you are authorized to archive, this is a good starting command:

mkdir "D:\YouTube\Channel-Backup"
cd /d "D:\YouTube\Channel-Backup"
yt-dlp -f "bv*+ba/b" --merge-output-format mp4 --download-archive downloaded.txt --write-thumbnail --embed-metadata -o "%(upload_date)s - %(title)s [%(id)s].%(ext)s" "https://www.youtube.com/@CHANNEL_HANDLE/videos"
Tip: Replace @CHANNEL_HANDLE with the actual YouTube handle. For example, https://www.youtube.com/@InjectionByRachel/videos. If the channel is large, make sure your drive has enough free space before starting.

10. Final checklist

  • Install and test yt-dlp.
  • Install and test FFmpeg.
  • Create a dedicated download folder.
  • Use --download-archive downloaded.txt for restart-safe downloads.
  • Use %(upload_date)s, %(title)s and %(id)s to keep filenames organized.
  • Use browser cookies only for accounts and content you are authorized to access.
  • Respect copyright, privacy, YouTube's terms and applicable law.
